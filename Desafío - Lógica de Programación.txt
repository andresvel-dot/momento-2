Title: Módulo de Ventas Iterativo con Estadísticas de Catálogo
Description:
El sistema de Catálogo Local requiere un módulo de caja registradora que procese múltiples artículos en una sola transacción. Partiendo de las variables base de un producto, el estudiante debe construir un programa en Java que utilice un ciclo do-while para mantener la caja abierta. Dentro del ciclo, se debe desplegar un menú, usando if, else if con 3 productos predefinidos del catálogo(básico, medio, premiun) y una opción para "Finalizar compra".

Además, el programa debe calcular e imprimir el porcentaje exacto de artículos "premium" (Producto 3) vendidos sobre el total de la transacción.
